# 音速測定アプリ（持ち運び用）

このフォルダーは、音速測定UIの実行に必要なプログラムと既定CSVを
1か所へまとめたものです。リポジトリ内の元ファイルには依存していないため、
`sound_velocity_app` フォルダー全体を別の場所や別PCへコピーして使用できます。

## ファイル構成

```text
sound_velocity_app/
├── main.py                    # 起動入口
├── app_settings.py            # 設定ファイルの保存・読込・検証
├── analysis_pipeline.py       # フィルター・波形照合・音速計算
├── data_sources.py            # CSV読み込み
├── window_functions.py        # 窓関数の生成・保存
├── picoscope_acquisition.py   # PicoScope波形取得
├── requirements.txt           # Python依存パッケージ
├── settings.json              # 起動時に自動で読み込む設定
└── data/
    ├── hand-0001.csv          # 既定の測定CSV
    └── zero_ref.csv           # 既定の参照CSV
```

## 初回セットアップ

Python 3.12以降を用意し、このフォルダー内で仮想環境と依存パッケージを
セットアップします。

macOS / Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

LinuxでTkinterがPythonに同梱されていない場合は、ディストリビューションの
パッケージ管理機能で `python3-tk` などもインストールしてください。

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

また、パソコンの環境に合った最新のPicoScopeアプリのインストールが必要
PicoScopeアプリをインストールするとドライバも自動でインストールされる。
（20260827時点の検証環境:
PicoScope 7 T&M,
ドライババージョン:PS5000A MacOSX Driver 2.2.16.5110）


## 起動

仮想環境を有効にした状態で実行します。

```bash
python main.py
```

`main.py` を絶対パスで指定すれば、このフォルダー以外をカレント
ディレクトリにして起動しても動作します。画面に入力する相対CSVパスは、
カレントディレクトリではなく、このフォルダーを基準に解決されます。


## 設定ファイル

起動時に、このフォルダー内の `settings.json` を自動で読み込みます。画面の
「設定を保存」を押すと、取得元、CSVパス、PicoScope、フィルター、窓関数、
照合、距離、表示範囲の全設定が同じファイルへ保存され、次回起動時に復元されます。
「設定を読み込む」を押すと、起動後にもファイルの内容を再読込できます。

設定を再読込すると、設定と波形の組み合わせが食い違わないよう、取得済みの
参照・実測データは破棄されます。参照データから取り直してください。
同梱CSVへのパスは `data/zero_ref.csv` のような相対パスで保存されるため、
フォルダー全体を別の場所へ移動してもそのまま使用できます。


## 画面タブ

「基本」タブには、波形取得、PicoScopeの入力レンジ変更、距離入力、フィルター後波形、
評価関数、主要な計算結果だけを表示します。基本タブで取得するときの
Channel Aレンジは±20 V固定です。Channel Bレンジは画面内の大きな
「−」で一段大きく、「＋」で一段小さく変更でき、現在値はアドバンスドタブへも同期されます。
フィルター後グラフのY軸はChannel Bレンジの±120%に固定され、レンジの
±60%位置に横方向のガイド線を表示します（±5 V設定ならY軸は±6 V、ガイド線は±3 V）。
「参照波形を取得」と「実測波形を取得・計算」の2つのボタンを常に表示し、
参照波形を必要なタイミングで取り直してから実測を開始できます。
表示時間は基本タブの「通常（40 µs）」「拡大（80 µs）」から切り替えられ、
アドバンスドタブの表示開始・終了にも同期します。
Channel Bレンジを基本タブの「−」「＋」で変更すると、変更後のレンジで
実測波形を自動的に取り直し、「データフィルタ後」だけを表示します。このレンジ確認時は
評価関数と音速を表示せず、距離欄から通常計測した場合にのみ表示します。
変更前の実測データと解析結果は破棄しますが、参照波形は保持されます。
自動取得時に実際の時間分解能（サンプリング間隔）を参照波形と比較し、変わっていた
場合だけ参照波形を破棄して再取得を求めます。Channel Aレンジを変更した場合は、
従来どおり参照波形を取り直します。

「アドバンスド」タブには、従来の全設定、全実行ボタン、4つのグラフ、計算結果を
そのまま配置しています。Channel A/Bレンジも従来どおりプルダウンで選択できます。
どちらのタブでも距離欄でEnterを押すと、新しい実測波形を
取得して再計算します。計算完了後は、現在表示中のタブの距離欄が自動選択されます。
基本タブの「−」「＋」でChannel Bレンジを変更した直後も距離欄が自動選択されるため、
続けて距離を入力して計測できます。


## 計測方法
main.pyを起動し、実験機に電源、PicoScopeとPCがUSBで接続されていることを確認する。
また、ノギスの電源を入れてゼロ点を校正し、PCとノギスをBluetoothで接続する。
リファレンス波形を取得する。センサ部にエコーゼリーを塗布、ノギスを0.00mmで閉じた状態で「参照波形を取得」ボタンを押す。この時は画面に変化は起こらない。
計測する。「距離[mm](任意)」の欄の数字を消してカーソルを合わせ、半角入力にしてノギスのデータ送信ボタンを押すと波形が計測され、音速が計算される。
2回目以降は計測後に距離の部分が自動で選択されるため、送信ボタンを押せば連続で音速を計測することができる。
